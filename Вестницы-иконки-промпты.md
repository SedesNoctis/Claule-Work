# Вестницы — промпты иконок (9 наборов)

Один набор — один путь, одна генерация. Можно растянуть на несколько дней, порядок любой: пока иконки нет, игра показывает руну-заглушку.

Стиль тот же, что у архитектов и Страйдеров: пергамент, чернила, золото.
- **Ромбовидная рамка** — эмблема пути (первая иконка каждого листа).
- **Круглая рамка** — активки камней.

Эмблема — символ пути, а не сценка. Активки — то, что делает камень.

Общий хвост стиля уже вставлен в каждый промпт, менять его не нужно.
