# Фреймворк: магия, ритуалистика, артефакторика

Здесь собирается то, что потом уйдёт в отдельный фреймворк (общий для всех, без лора Авир).

- `Magic/` — система магии: план с лором (`Магия-план.md`) и снимок кода, определений и текстур магии на последнюю сборку (`Source/`, `Defs/`, `Textures/`, `Languages/`).
- Ритуалистика и артефакторика добавятся сюда же, когда начнём выносить их.

Снимок обновляется с каждой сборкой магии.
