# Арканные работы и самосборные чары — черновик (на согласование автору)

Основа — замысел автора (сообщение после Fix151). Что уже есть в коде, отмечено «есть».

## 1. Самосборные чары (примеров нет и не будет)
- Сейчас (есть): любая арканная работа делается «простым заговором» без заклинания; если в книге есть бытовое заклинание под эту работу (стихии работы + её руны), работа делается им — шире, сильнее, дальше.
- Будет: заговор становится настоящим заклинанием, которое пешка собирает сама, когда впервые берётся за работу своей стихии. Оно записывается в её книгу с подписью «собрано самим» и видно игроку: его можно открыть в редакторе и улучшить.
- Сборка по правилам, а не случайно: стихии работы + руны работы (таблица WorkSpells.Runes, есть) + модификаторы по ступени: Ширина с Адепта, Усиление с Эксперта, Дальность — земле с Ученика.
- Тот же сборщик — для врагов: боевые чары по ступени и стихии (сейчас есть только случайный SpellGen для чужаков).

## 2. Кто и как работает
- Своя стихия (путь) — с Новичка. Чужая стихия — с Ученика.
- Сочетания (пара) — с Новичка, но с риском последствий (раздел 3). Второй порядок — как сейчас: с Адепта в удвоенной стихии (есть).
- Скорость работы по ступени: Новичок ×0,7, Ученик ×0,85, Адепт ×1, Эксперт ×1,2, Мастер ×1,4, Грандмастер ×1,6.

## 3. Последствия
- Каждый каст работы проверяет удержание, как заклинание, но мягче. При срыве — цена стихии, ослабленная для работы: огонь — короткое пламя у ног, вода — промокание, земля — скованность, воздух — одышка.
- Опасные школы бьют серьёзно: магма и лава — лужа магмы вокруг мага, ожоги; пар — ошпаривание; гроза — разряд.
- На странице «Путь» и на шкалах — настройка «с какой ступени пешка берётся за работы этой школы» (Новичок … Грандмастер, «никогда»). По умолчанию: простые стихии — с Новичка, сочетания — с Ученика, магма и лава — с Адепта.

## 4. Вкладка «Работы»
- Только у пешек с магией; у остальных ничего не меняется.
- Ячейка обычной работы, которую можно делать магией: если навык плохой (красный) или работа запрещена Величием, она подсвечивается синим.
- К приоритетам 1–2–3–4 добавляется «М»: эту работу пешка делает только магией, а какими именно чарами и в каком порядке — решает подвкладка.
- Подвкладка «Арканные работы» — переключатель вверху вкладки «Работы» (отдельная таблица, обычные столбцы не засоряются): строки — маги, столбцы — арканные работы по школам, свои приоритеты.
- Работы, закрытые Величием, сами получают «М», если для них есть магическая замена. Величие запрещает работу руками, магией — нет (сейчас так и есть: арканные работы в своём типе работ, Величие их не трогает).
