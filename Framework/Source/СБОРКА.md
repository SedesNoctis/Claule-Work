# Полный исходный код мода и сборка

`Avir/` — полный исходный код `Avir.dll` (все системы). `Avir/_Recovered/` — типы, восстановленные декомпиляцией последней DLL (Magic92) 5 ноября 2026: их исходники нигде не сохранились, в них нет комментариев; поведение совпадает с DLL. Остальные папки (AvirHautsCompat, AvirRJW и т. д.) — другие сборки, как пришли от автора.

Сборка: .NET SDK 8, `dotnet build -c Release Avir.build.csproj -p:SRC=<путь>/Avir` (пакеты Krafs.Rimworld.Ref 1.6.4871, Lib.Harmony 2.3.6).
